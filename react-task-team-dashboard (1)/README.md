# React Task & Team Management Dashboard

A responsive React.js frontend for the internship assignment.

## Features

- Login page with validation
- Forgot password page with validation
- Dashboard stats cards
- Task listing with search/filter/create/edit/delete
- Team members list with add member form
- Responsive design for desktop, tablet, and mobile

## Run locally

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```
